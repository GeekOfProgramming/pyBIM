## 📖 About The Project

**Arvand Termotec** is a modern, high-performance corporate website built to showcase premium engineering services. From HVAC and plumbing to solar energy and security systems, the platform provides a seamless and visually stunning experience for clients seeking top-tier technical solutions.

Built with **Next.js 14** (App Router) and **Tailwind CSS**, it features a fully responsive design, modern UI components, and optimized performance.

## ✨ Features

- **⚡ Blazing Fast:** Powered by Next.js 14 and React 18.
- **🎨 Beautiful UI:** Fully styled with Tailwind CSS and Lucide React icons.
- **📱 Responsive Design:** Flawless experience across all devices (Mobile, Tablet, Desktop).
- **🖼️ Optimized Media:** Integrated with Cloudinary for fast and optimized image delivery.
- **🌐 SEO Optimized:** Built-in metadata and Next.js optimizations for better search rankings.
- **🔄 Smooth Carousels:** Interactive galleries and testimonials using Embla Carousel.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Components:** [Embla Carousel](https://www.embla-carousel.com/)
- **Media Management:** [Cloudinary](https://cloudinary.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have Node.js (v18+) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arvandtermotec-maker/June2026.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd June2026
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application in action.

## 📂 Project Structure

- `/app`: Next.js App Router files (Pages, Layouts, APIs).
- `/components`: Reusable UI components (Navbar, Footer, Cards, etc.).
- `/public`: Static assets like images and icons.
- `/lib`: Utility functions and configuration files.
